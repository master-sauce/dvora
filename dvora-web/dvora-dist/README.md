# DVORA — Browser UI

## Run
```bash

# Windows
start_windows.bat

# Mac
start_linux_mac.sh

# open http://localhost:8080

```

## Site File Format
- `+url` → spaces become `+` in search term
- `-url` → spaces become `-`
- plain url → spaces kept
- Lines starting with `#` are comments

Edit all files from the Settings panel in the browser.
